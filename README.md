# 식비 절약 계산 서비스

집에서 요리할 때 필요한 재료비와 외식 기준 가격을 비교하고, 사용자가 실제로 요리한 기록을 바탕으로 예상 절약액을 모아 보는 웹 서비스입니다.

## MVP 목표

사용자가 메뉴와 인분 수를 고르고 보유 재료를 표시하면 다음 금액을 구분해 보여줍니다.

- **추가 구매 예상액:** 부족한 재료를 포장 단위로 구매할 때 필요한 금액
- **요리 재료비:** 레시피에서 실제 사용할 분량의 재료비
- **외식 기준 가격:** 선택한 지역의 메뉴 기준 가격 또는 사용자가 입력한 가격
- **예상 차액:** 외식 기준 가격에서 요리 재료비를 뺀 값

절약 기록은 요리 완료를 사용자가 확인한 시점에 저장합니다. 계산 결과에는 가격 출처와 기준일을 함께 표시하는 것을 원칙으로 합니다.

## 기술 스택

- 프론트엔드: Vue.js
- 백엔드: Java, Spring Boot
- 데이터베이스: PostgreSQL

## MVP 기능

1. 메뉴 검색 및 상세 보기
2. 인분 수와 보유 재료 입력
3. 추가 구매 예상액, 요리 재료비, 외식 기준 가격 비교
4. 요리 완료 기록 및 누적 예상 절약액 조회
5. 관리자용 참가격 파일 업로드, 검증 및 반영

## 데이터 설계 초안

- 재료와 별칭
- 메뉴, 레시피 버전, 레시피 재료
- 재료 가격 이력
- 외식 메뉴 기준 가격 이력
- 참가격 파일 적재 배치 및 검증 결과
- 사용자 보유 재료와 절약 계산 스냅샷

## 참가격 데이터 적재 방향

초기 버전은 관리자 파일 업로드를 통해 데이터를 적재합니다. 원본 파일과 배치 메타데이터를 보존하고, 검증·미리보기 후 승인된 데이터만 반영합니다. 동일 파일을 다시 처리해도 가격 이력이 중복 생성되지 않도록 원천 코드, 지역, 기준일, 가격 단위 등을 기준으로 중복을 제어합니다.

## 로컬 개발

### 프런트엔드

로그인 MVP 화면은 `frontend/`에 있습니다. [Vue 공식 시작 가이드](https://vuejs.org/guide/quick-start.html)의 Node.js 요구 버전을 설치한 뒤 실행합니다.

```bash
cd frontend
npm install
npm run dev
```

현재 로그인, 회원가입, 비밀번호 재설정 API는 연결되지 않았으며 화면 상호작용과 입력 검증만 구현되어 있습니다.

### 백엔드

Spring Boot API는 `backend/`에 있습니다. Amazon RDS for PostgreSQL 연결 설정, 로그인·회원가입 API, OAuth 확장을 고려한 인증 구조와 IntelliJ 실행 방법은 [백엔드 README](backend/README.md)를 참고합니다.

현재 백엔드는 JWT 서명키와 PostgreSQL 접속 정보를 환경변수로 받으며, 로컬 자격 증명 로그인/회원가입만 구현되어 있습니다. 프런트엔드 회원가입·로그인 화면은 아직 API와 연결되지 않았습니다.
